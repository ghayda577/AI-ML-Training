# Day 5 — Full Exploratory Data Analysis (EDA) Notebook

## Overview

This task focuses on building a complete Exploratory Data Analysis (EDA) notebook that combines statistical analysis, data visualization, and relationship exploration.

The goal was to analyze a real dataset, discover important patterns, understand relationships between variables, and summarize insights through data storytelling before applying Machine Learning models.

## Learning Objectives

- Build a complete EDA workflow from data exploration to insights.
- Perform univariate and bivariate analysis.
- Analyze relationships between numerical and categorical variables.
- Compute and interpret correlation between features.
- Visualize relationships using different plotting techniques.
- Communicate EDA findings through clear Markdown explanations.

## Hands-On Lab

The complete EDA notebook was created using Python, Pandas, Seaborn, and Matplotlib.

The following tasks were completed:

1. **Dataset Overview**
   - Loaded and inspected a real dataset.
   - Checked dataset structure, data types, and basic information.
   - Identified numerical and categorical variables.

2. **Statistical Analysis**
   - Calculated descriptive statistics.
   - Analyzed measures such as mean, median, standard deviation, and data ranges.
   - Used statistical summaries to understand the dataset characteristics.

3. **Univariate Analysis**
   - Created visualizations to explore individual variables.
   - Used histograms, count plots, and box plots to analyze distributions.
   - Examined variable spread, skewness, and possible unusual patterns.

4. **Outlier Detection**
   - Applied the IQR method to identify potential outliers.
   - Visualized outliers using box plots.
   - Evaluated how outliers should be handled before modeling.

5. **Bivariate Analysis**
   - Created scatter plots to analyze relationships between numerical variables.
   - Used grouped box plots to compare numerical features across categories.
   - Investigated differences between employee groups.

6. **Correlation Analysis**
   - Computed the correlation matrix using numerical features.
   - Visualized correlations using an annotated heatmap.
   - Identified the strongest relationships between variables.
   - Explained the meaning of important correlations.

7. **Data Storytelling**
   - Converted analysis results into meaningful insights.
   - Explained important patterns discovered in the dataset.
   - Discussed how identified relationships may support future Machine Learning models.
