# Day 3 — Linear Algebra for Machine Learning

## Overview

This task introduces the fundamental concepts of linear algebra used in Machine Learning through practical examples with NumPy.

## Learning Objectives

- Understand vectors and matrices.
- Compute the dot product manually and using NumPy.
- Use matrix multiplication to generate predictions.
- Understand shape mismatch errors and how to fix them.

## Topics Covered

- Vectors
- Matrices
- Dot Product
- Matrix Multiplication
- Shape Compatibility

## Hands-On Lab

The following tasks were completed using Python and NumPy:

1. **Data Matrix**
   - Represented three data samples as a NumPy matrix.

2. **Dot Product**
   - Selected one sample vector.
   - Computed the dot product manually.
   - Verified the result using `np.dot()`.

3. **Matrix Multiplication**
   - Used the `@` operator to generate predictions for all samples at once.

4. **Shape Mismatch Error**
   - Intentionally created a shape mismatch error.
   - Explained why the error occurred.
   - Corrected the dimensions to perform successful matrix multiplication.

## Tools Used

- Python
- NumPy
- Jupyter Notebook

## Conclusion

This task provided hands-on practice with the core linear algebra operations used in Machine Learning. Understanding vectors, matrices, and matrix multiplication is essential for building and understanding ML models.
