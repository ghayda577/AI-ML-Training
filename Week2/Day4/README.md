# Day 4 — Exploratory Data Analysis (EDA) Part 1: Distributions & Outliers

## Overview

This task introduces the fundamentals of Exploratory Data Analysis (EDA) using Python visualization libraries.

The goal was to understand dataset distributions, analyze individual variables, and detect potential outliers before applying Machine Learning models.

## Learning Objectives

- Understand why EDA is an important step before modeling.
- Perform univariate analysis using statistical visualizations.
- Create different plots using Seaborn.
- Detect outliers using the IQR method.
- Analyze numerical and categorical variables.

## Topics Covered

- Exploratory Data Analysis (EDA)
- Seaborn Visualization
- Histogram
- Box Plot
- Count Plot
- KDE Plot
- Outlier Detection using IQR

## Hands-On Lab

The following tasks were completed using Python, Pandas, Seaborn, and Matplotlib:

1. **Dataset Exploration**
   - Loaded a real dataset.
   - Identified numerical and categorical variables.

2. **Distribution Analysis**
   - Created histograms for numerical variables.
   - Analyzed the distribution shape, spread, and possible skewness.

3. **Outlier Detection**
   - Generated box plots to visualize potential outliers.
   - Applied the IQR method to detect unusual values.
   - Evaluated whether detected outliers should be kept, removed, or handled.

4. **Categorical Analysis**
   - Created count plots for categorical variables.
   - Observed category frequencies and possible class imbalance.

5. **EDA Documentation**
   - Documented observations from each visualization.
   - Explained what each distribution revealed about the dataset.

This task provided practical experience with Exploratory Data Analysis techniques used before Machine Learning modeling.
