# Day 2 — Probability & Distributions

## Overview
This task covers the basic concepts of probability and probability distributions, which are important foundations for Machine Learning and data analysis.

## Learning Objectives
- Understand basic probability concepts and rules.
- Apply complement, addition, and multiplication rules.
- Learn conditional probability and Bayes' theorem.
- Explore common probability distributions: Normal, Binomial, and Uniform.

## Topics Covered
- Probability basics
- Complement, Addition, and Multiplication rules
- Conditional Probability
- Bayes' Theorem
- Normal Distribution
- Binomial Distribution
- Uniform Distribution

## Hands-On Lab
Using Python, NumPy, and Matplotlib, the following experiments were implemented:

1. **Coin Flip Simulation**
   - Simulated 10,000 coin flips.
   - Verified that the probability of getting heads approaches 0.5.

2. **Normal Distribution Simulation**
   - Generated random values using NumPy's normal distribution.
   - Visualized the data using a histogram to observe the bell-shaped curve.

3. **Conditional Probability**
   - Calculated conditional probability using a given scenario.
   - Verified the result through simulation.

4. **Results Documentation**
   - Added Markdown explanations for each experiment and its results.
